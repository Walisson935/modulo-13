# Projeto Final - Análise de Dados de Supermercado

## Objetivo

Este projeto realiza uma análise exploratória de dados de um supermercado utilizando Python e Pandas.

## Ferramentas

- Python
- Pandas
- Plotly
- Jupyter Notebook

## Estatísticas

- Quantidade de produtos
- Quantidade de categorias
- Quantidade de marcas
- Média dos preços
- Mediana
- Desvio padrão
- Maior e menor preço

## Visualizações

- Produtos por categoria
- Preço médio por categoria
- Top 10 marcas

## Como executar

```bash
pip install -r requirements.txt
```

Depois execute:

```
analise_supermercado.ipynb
```
